Hubungkan ke Firebase Database
Gratis & langsung jalan tanpa konfigurasi rumit
1. Buka console.firebase.google.com → buat project baru
2. Klik Realtime Database → Create Database → pilih lokasi → Start in test mode
3. Salin URL database (format: https://nama-rtdb.firebaseio.com)
4. Project Settings → Service accounts → Database secrets → salin secret
Gunakan URL + Secret yang sama di semua perangkat.
